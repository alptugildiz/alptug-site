# Gider Takip Sayfası Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Şifreli `/giderler` sayfası: Alptuğ ve Gamze kendi giderlerini girer, ikisinin aylık kategori toplamlarını da görür; veri kalıcı volume'deki bir JSON dosyasında.

**Architecture:** Saf mantık (`src/lib/giderler/*`: kategoriler, para, auth kriptosu, JSON store, özet) Node'un yerleşik test runner'ıyla test edilir. Next tarafı ince: `session.ts` cookie'yi okur, Server Actions yazımları yapar, `page.tsx` sunucu bileşeni veriyi okuyup küçük client form bileşenlerine verir.

**Tech Stack:** Next.js 16 App Router (Server Actions, `useActionState`), React 19, Tailwind 4, `node:crypto` (scrypt + HMAC), `node:test` (Node 24, type stripping varsayılan açık). Yeni npm bağımlılığı yok.

**Spec:** `docs/superpowers/specs/2026-11-17-giderler-design.md`

## Global Constraints

- Yeni npm bağımlılığı yok. Kripto: `node:crypto`. Test: `node:test` + `node:assert/strict`.
- `src/lib/giderler/*.ts` dosyaları birbirini **göreli yol + `.ts` uzantısıyla** import eder (`./categories.ts`) ve `@/` alias'ı kullanmaz; böylece `node --test` doğrudan çalıştırır. Bunun için `tsconfig.json`'a `"allowImportingTsExtensions": true` eklenir (`noEmit` zaten açık).
- Env: `GIDER_ALPTUG_PASSWORD_HASH`, `GIDER_GAMZE_PASSWORD_HASH` (format `scrypt$<saltHex>$<hashHex>`), `GIDER_SESSION_SECRET` (≥32 karakter), `GIDER_DATA_DIR` (varsayılan `./data`; prod'da `/app/data`).
- Kullanıcılar: `"alptug" | "gamze"`, görünen adları `Alptuğ`, `Gamze`.
- Kategoriler (sıra ve etiketler sabit): `ulasim` Ulaşım, `kozmetik` Kozmetik, `yemek` Yemek, `faturalar` Faturalar, `psikolog` Psikolog, `spor` Spor, `tatli` Tatlı / abur cubur, `ev` Ev giderleri, `giyim` Giyim, `diger` Diğer.
- Tutarlar kuruş cinsinden pozitif tamsayı; gösterim `Intl.NumberFormat("tr-TR", { style: "currency", currency: "TRY" })`.
- Cookie: adı `gider_session`, `httpOnly`, `secure` (prod'da), `sameSite: "lax"`, `path: "/giderler"`, ömür 30 gün.
- Sayfa: `robots: { index: false, follow: false }`; `robots.ts`'de `/giderler` disallow; sitemap'e ve siteye link eklenmez. Sayfa metinleri Türkçe.
- Yazma yetkisi: bir kaydı yalnızca `owner`'ı güncelleyebilir/silebilir — Server Action içinde sunucu tarafında kontrol edilir.

## Review Focus

- **Virgüllü/noktalı tutar girişi** (`"1.250,50"`, `"89,90"`, `"45"`, `"0"`, `"-5"`, `"abc"`): Türk formatı doğru kuruşa çevrilmeli; sıfır/negatif/çöp reddedilmeli → `money.test.ts`'de `parseAmount` testleri.
- **Eşzamanlı iki yazım** (ikiniz aynı anda kayıt eklersiniz): ikisi de dosyada kalmalı → `store.test.ts` "concurrent adds".
- **Dosya yok / ilk çalıştırma** (`/app/data` boş volume): boş liste dönmeli, ilk eklemede dosya oluşmalı → `store.test.ts`.
- **Başkasının kaydını silme/düzenleme** (Gamze, Alptuğ'un kayıt id'siyle action çağırır): reddedilmeli, dosya değişmemeli → `store.test.ts` "owner mismatch".
- **Bozuk/süresi geçmiş/oynanmış cookie veya env'de hash eksik**: giriş ekranına düşmeli, hata fırlatmamalı → `auth.test.ts`.

### Task 2: Auth kriptosu + rate limit

**Files:**
- Create: `src/lib/giderler/auth.ts`
- Test: `src/lib/giderler/auth.test.ts`
- Create: `scripts/gider-hash.mjs`

**Interfaces:**
- Consumes: `UserId`, `isUser` (Task 1).
- Produces:
  - `hashPassword(password: string): string` → `scrypt$<salt>$<hash>` (16 byte salt, 64 byte key).
  - `verifyPassword(password: string, stored: string | undefined): boolean` — `timingSafeEqual`; `stored` yok/bozuksa `false`.
  - `signSession(user: UserId, secret: string, now?: number): string` → `<base64url payload>.<base64url hmac>`, payload `{ u, exp }`, exp = now + 30 gün.
  - `verifySession(token: string | undefined, secret: string | undefined, now?: number): UserId | null`.
  - `SESSION_MAX_AGE_S = 60*60*24*30`.
  - `createLoginLimiter(max = 5, windowMs = 15*60_000)` → `{ check(key: string, now?: number): boolean; fail(key: string, now?: number): void; reset(key: string): void }`.

- [ ] **Step 1: Write failing tests:**
  - `verifyPassword("gizli", hashPassword("gizli")) === true`; yanlış şifre `false`; `stored` `undefined`/`""`/`"garbage"` → `false`.
  - İki `hashPassword("x")` çağrısı farklı (salt).
  - `verifySession(signSession("gamze", S), S) === "gamze"`; farklı secret → `null`; payload'da tek karakter değişmiş → `null`; `now` 31 gün sonra → `null`; `undefined` token veya secret → `null`; payload'da `u: "admin"` → `null`.
  - Limiter: 5 `fail` sonra `check` `false`; pencere geçince `true`; `reset` sonrası `true`.
- [ ] **Step 2:** `npm test` → FAIL.
- [ ] **Step 3: Implement** `scryptSync`, `createHmac("sha256")`, `timingSafeEqual` (uzunluk farkında önce `false`). `verifySession` hiçbir girdi için fırlatmaz (try/catch). `scripts/gider-hash.mjs`: şifreyi `process.argv[2]`'den alır, aynı formatta hash basar (mantığı `auth.ts` ile aynı parametrelerle; script'in import edemeyeceği için kısa kopya kabul — başına yorum).
- [ ] **Step 4:** `npm test` → PASS. `node scripts/gider-hash.mjs deneme` çıktısı `scrypt$` ile başlar ve `verifyPassword("deneme", çıktı)` true (testte de doğrula: script çıktısını `execFileSync` ile al).
